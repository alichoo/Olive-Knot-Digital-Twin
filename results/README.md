# Evaluation Results

- `paper_summary_metrics.csv`: Published summary metrics corresponding to Tables 9–18 of the manuscript (200 held-out ERA5 seasons, 2015–2023 weather pool).
- `raw_test_seasons.csv` (generated by `scripts/evaluate.py`): Per-season metrics (`method, season_seed, region, burden_pp, copper_per_sector, flights, latency, violations, interventions, cost_J`) across all 200 test seasons.
